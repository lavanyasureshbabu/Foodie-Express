# Foodie Express

## Food Delivery App

### Sprint Development

## Project Description
Foodie Express is a food delivery application prototype that allows users to explore restaurants, view food menus, add items to a cart, and proceed to payment.

## Features
- User Login and Registration
- Location Selection
- Food Search
- Food Categories
- Restaurant Menu
- Shopping Cart
- Payment Page
- Order Tracking
- Ratings and Reviews
- User Profile
- Order History

## Technologies Used
- HTML
- Git
- GitHub

## Development Increments
- Sprint 1: Login, User Registration, and Restaurant Search
- Sprint 2: View Menu, Add Food to Cart, and Place an Order
- Sprint 3: Online Payment and Order Tracking

## Project Status
This project is a basic HTML prototype developed for academic purposes.
